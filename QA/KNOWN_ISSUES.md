# Известные проблемы

## Подтверждённые дефекты

На выполненном объёме тестирования подтверждённых дефектов не зарегистрировано.

## Ограничения и непроверенные области

### LIM-001 — real localStorage не проверен браузерным smoke-стендом

- **Причина:** среда выполнения блокирует навигацию к `localhost`, `file://` и тестовому HTTP origin. Приложение запускалось через `page.set_content`, который имеет opaque origin и запрещает доступ к `localStorage`.
- **Компенсация:** миграция, чтение и запись сохранений покрыты 19 Node-тестами с управляемым storage mock.
- **Статус:** `BLOCKED`, не подтверждённый дефект игры.

### LIM-002 — Yandex Games SDK не проверен на реальной платформе

- Rewarded и полноэкранная реклама проверялись только на уровне mock-callbacks.
- `LoadingAPI` и `GameplayAPI` не проверялись в Yandex Games Debug Panel.
- Статус: `NOT_RUN`.

### LIM-003 — ограниченная матрица совместимости

Динамический smoke выполнен только в Chromium на разрешениях 1440×900 и 390×844. Firefox, Safari и реальные мобильные устройства не тестировались.

## Наблюдения, не являющиеся дефектами

- В ресурсах есть три группы точных дубликатов изображений режимов. Они оставлены без удаления, поскольку разные имена могут быть частью публичной структуры ресурсов.
- `aria-labelledby="modalTitle"` ссылается на элемент, который создаётся динамически при открытии модального окна. В исходной статической разметке этого ID нет, что ожидаемо для текущей реализации.

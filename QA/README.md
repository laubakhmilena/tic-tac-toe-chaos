# QA-документация

| [`TEST_PLAN.md`](TEST_PLAN.md) | Область, подход и ограничения тестирования |
| [`TEST_CASES.md`](TEST_CASES.md) | Оформленные автоматические и smoke-проверки |
| [`SMOKE_CHECKLIST.md`](SMOKE_CHECKLIST.md) | Короткий ручной smoke-набор перед публикацией |
| [`TEST_EXECUTION_REPORT.md`](TEST_EXECUTION_REPORT.md) | Фактические результаты выполненных проверок |
| [`KNOWN_ISSUES.md`](KNOWN_ISSUES.md) | Подтверждённые проблемы и ограничения проверки |

| [`logs/`](logs/) | Вывод автоматических проверок |

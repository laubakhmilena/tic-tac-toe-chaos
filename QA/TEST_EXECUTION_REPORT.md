## Заблокированные проверки

Два пункта проверки реального `localStorage` заблокированы. Среда не разрешала браузеру переходить к локальному или тестовому origin, поэтому приложение запускалось через `page.set_content` с opaque origin. В таком документе браузер запрещает чтение `localStorage`.

Это не зарегистрировано как дефект игры: миграция и сохранения отдельно покрыты unit-тестами с контролируемым хранилищем. Для окончательного подтверждения требуется ручной запуск через `http://localhost` или GitHub Pages.

# План тестирования

## Объект

Адаптивная браузерная игра «Крестики Нолики Хаос».

## Цели

1. Подтвердить, что проект можно безопасно опубликовать в GitHub как статическое веб-приложение.
2. Проверить синтаксис и целостность структуры.
3. Выполнить существующие тесты сохранений и питомца.
4. Дополнить покрытие основной игровой логики.
5. Выполнить браузерный smoke критического пользовательского пути.
6. Зафиксировать непроверенные платформенные функции.

## В области проверки

- запуск приложения;
- переходы Home → Modes → Setup → Game;
- запуск четырёх режимов;
- классическая победа в локальной игре;
- адаптивность на 1440×900 и 390×844;
- отсутствие горизонтального переполнения документа в smoke-сценарии;
- логика классического, стратегического, бесконечного и исчезающего режимов;
- AI-решения для немедленной победы и блокировки;
- миграция сохранений;
- открытие тем;
- питомец, дружба, награды, сундуки и rewarded-лимиты;
- синтаксис JavaScript;
- существование ресурсов и уникальность HTML ID;
- читаемость графических файлов.

## Вне области или заблокировано

- реальная Yandex Games площадка;
- полноэкранная и rewarded-реклама в production SDK;
- физические мобильные устройства;
- Safari и Firefox;
- реальная вибрация и качество звука;
- длительная сессия;
- визуальная проверка всех тем и аксессуаров;
- реальный `localStorage` в браузерном smoke-стенде из-за ограничения origin.

## Типы тестирования

- статический анализ структуры;
- unit-тестирование;
- браузерный smoke;
- функциональная проверка критического пути;
- базовая проверка совместимости разрешений;
- проверка ресурсов;
- негативные проверки повреждённых и устаревших сохранений.

## Критерии готовности к GitHub

- `npm run verify` завершается успешно;
- нет отсутствующих обязательных файлов;
- нет отсутствующих статически указанных ресурсов;
- главная страница и все четыре режима запускаются;
- отсутствуют подтверждённые блокирующие дефекты;
- README и инструкция загрузки присутствуют.

# Крестики Нолики Хаос

Адаптивная браузерная игра в крестики-нолики с четырьмя режимами, игрой против компьютера или друга на одном устройстве, открываемыми темами и постоянным питомцем — Кошечкой Хаос.

Проект написан на чистых HTML, CSS и JavaScript. Сборщик и обязательные runtime-зависимости не требуются.

## Возможности

- четыре игровых режима;
- противник-компьютер с тремя уровнями сложности;
- локальная игра для двух игроков на одном устройстве;
- восемь визуальных тем с разными символами;
- статистика матчей и система открытия тем;
- адаптивный интерфейс для компьютеров и мобильных устройств;
- музыка, звуки и вибрация;
- локальное сохранение прогресса;
- сохранение незавершённых партий в стратегическом и бесконечном режимах;
- Кошечка Хаос: дружба, ежедневные задания, угощения, сундуки и аксессуары;
- интеграция с Yandex Games SDK для рекламы и сигналов игрового процесса.

## Игровые режимы

| Режим | Правила |
|---|---|
| **Классические** | Поле 3×3. Побеждает игрок, первым собравший три символа в ряд. |
| **Стратегические** | Девять связанных малых полей. Клетка текущего хода определяет малое поле для следующего игрока. Для победы нужно выиграть три малых поля в ряд. |
| **Бесконечные** | Перемещаемое и масштабируемое поле. Для победы требуется собрать пять символов подряд. |
| **Исчезающие** | У каждого игрока остаются только три знака. При установке четвёртого самый старый знак исчезает. |

## Темы

В новой игре сразу доступна тема **Классика**. Остальные темы открываются за игровые достижения:

- Солнце и Луна;
- Облако и Звезда;
- Котик и Клубок;
- Кофе и Пончик;
- Огонь и Вода;
- Космос;
- Лес.

## Кошечка Хаос

Питомец получает «лапки» за завершённые матчи и взаимодействия. Повышение уровня дружбы открывает сундуки с аксессуарами. Также доступны ежедневные подарки, задания, угощения и ограниченная награда за просмотр rewarded-рекламы на поддерживаемой платформе.

## Локальный запуск

### Python

Откройте терминал в корне проекта и выполните:

```bash
python -m http.server 8000
```

На Windows также может использоваться команда:

```powershell
py -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000
```

### Visual Studio Code

Можно использовать расширение **Live Server** и команду **Open with Live Server** для `index.html`.

## Автоматические проверки

Для запуска всех проверок нужен Node.js 20 или новее:

```bash
npm run verify
```

Отдельные команды:

```bash
npm test                 # 32 unit-теста
npm run check:syntax     # проверка синтаксиса JavaScript
npm run check:project    # проверка структуры и ссылок на ресурсы
```

При отправке изменений в GitHub те же проверки автоматически запускаются через GitHub Actions.

## Публикация через GitHub Pages

1. Загрузите содержимое этой папки в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и каталог `/ (root)`.
5. Сохраните настройки и дождитесь публикации.

## Сохранения

Прогресс хранится в `localStorage` под ключом:

```text
ticTacToeChaosSave
```

Сохраняются темы, статистика, настройки, прогресс питомца и поддерживаемые незавершённые партии. Очистка данных сайта в браузере удалит локальное сохранение.

## Yandex Games

При запуске на поддерживаемом домене игра пытается подключить `/sdk.js` и использует:

- `LoadingAPI.ready()`;
- `GameplayAPI.start()` и `GameplayAPI.stop()`;
- полноэкранную рекламу;
- rewarded-рекламу для награды питомца.

При обычном локальном запуске без SDK игра остаётся работоспособной, но рекламные возможности недоступны.

# Крестики Нолики Хаос

Адаптивная браузерная игра в крестики-нолики с четырьмя режимами, игрой против компьютера или друга на одном устройстве, открываемыми темами и постоянным питомцем — Кошечкой Хаос.

Проект написан на чистых HTML, CSS и JavaScript. Сборщик и обязательные runtime-зависимости не требуются.

## 🎮 Играть

Актуальная версия игры доступна на **Яндекс Играх**:

**[Играть в «Крестики Нолики Хаос»](https://yandex.ru/games/app/554837?lang=ru)**

## Возможности

* четыре игровых режима;
* противник-компьютер с тремя уровнями сложности;
* локальная игра для двух игроков на одном устройстве;
* восемь визуальных тем с разными символами;
* статистика матчей и система открытия тем;
* адаптивный интерфейс для компьютеров и мобильных устройств;
* музыка, звуки и вибрация;
* локальное сохранение прогресса;
* облачная синхронизация прогресса через Yandex Games Player API;
* сохранение незавершённых партий в стратегическом и бесконечном режимах;
* Кошечка Хаос: дружба, сытость, настроение, ежедневные задания, угощения и сундуки;
* открываемые настроения Кошечки Хаос;
* ежедневная мини-игра «Пятнашки» с наградами;
* rewarded-реклама с наградой для питомца;
* интеграция с Yandex Games SDK для рекламы, облачных сохранений и сигналов игрового процесса.

## Игровые режимы

| Режим              | Правила                                                                                                                                         |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Классические**   | Поле 3×3. Побеждает игрок, первым собравший три символа в ряд.                                                                                  |
| **Стратегические** | Девять связанных малых полей. Клетка текущего хода определяет малое поле для следующего игрока. Для победы нужно выиграть три малых поля в ряд. |
| **Бесконечные**    | Перемещаемое и масштабируемое поле. Для победы требуется собрать пять символов подряд.                                                          |
| **Исчезающие**     | У каждого игрока остаются только три знака. При установке четвёртого самый старый знак исчезает.                                                |

## Темы

В новой игре сразу доступна тема **Классика**. Остальные темы открываются за игровые достижения:

* Солнце и Луна — сыграть 3 завершённых матча;
* Облако и Звезда — одержать первую победу над компьютером;
* Котик и Клубок — одержать 3 победы над компьютером;
* Кофе и Пончик — победить компьютер 5 раз;
* Огонь и Вода — получить серию из 3 побед в режиме «Исчезающие»;
* Космос — победить в режиме «Стратегические»;
* Лес — победить в режиме «Бесконечные».

## Кошечка Хаос

Кошечка Хаос — постоянный питомец игрока.

За завершённые матчи, выполнение заданий и взаимодействие с питомцем начисляются **лапки дружбы**. Каждые 10 лапок повышают уровень дружбы и открывают **Сундук заботы**.

У питомца есть показатели:

* **сытость**;
* **настроение**;
* **уровень дружбы**.

Кошечку можно кормить и гладить. Для кормления используются разные угощения:

* рыбка;
* молоко;
* печенье;
* торт.

Сундуки могут содержать еду, дополнительные очки заботы, восстановление состояния питомца и редкие открываемые настроения.

### Настроения

В игре доступны разные образы и настроения Кошечки:

* Обычная;
* Радостная;
* Сонная;
* Игривая;
* Ласковая;
* Космическая;
* Праздничная;
* Мечтательная.

Часть настроений доступна сразу, остальные можно открыть через Сундуки заботы.

### Ежедневные задания

Каждый день питомец предлагает новое задание. Например:

* сыграть несколько матчей;
* победить компьютер;
* сыграть в разных режимах;
* победить в режиме «Исчезающие»;
* закончить стратегический матч;
* победить в бесконечном режиме.

За выполнение задания выдаются угощение и дополнительные лапки дружбы.

### Игра дня

В разделе питомца доступна мини-игра **«Пятнашки»**.

Нужно собрать изображение Кошечки из восьми подвижных плиток. За победу начисляются награды для питомца, а первая победа дня приносит увеличенную награду.

На поддерживаемых платформах также доступна ограниченная награда за просмотр rewarded-рекламы.

## Локальный запуск

### Python

Откройте терминал в корне проекта и выполните:

```bash
python -m http.server 8000
```

На Windows также может использоваться команда:

```powershell
py -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000
```

### Visual Studio Code

Можно использовать расширение **Live Server** и команду **Open with Live Server** для `index.html`.

## Автоматические проверки

Для запуска всех проверок нужен Node.js 20 или новее:

```bash
npm run verify
```

Отдельные команды:

```bash
npm test                 # unit-тесты
npm run check:syntax     # проверка синтаксиса JavaScript
npm run check:project    # проверка структуры и ссылок на ресурсы
```

При отправке изменений в GitHub те же проверки автоматически запускаются через GitHub Actions.

## Публикация через GitHub Pages

1. Загрузите содержимое проекта в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и каталог `/ (root)`.
5. Сохраните настройки и дождитесь публикации.

## Сохранения

Локальный прогресс хранится в `localStorage` под ключом:

```text
ticTacToeChaosSave
```

Сохраняются:

* открытые и выбранная темы;
* статистика матчей;
* настройки игры;
* выбранные уровни сложности;
* прогресс Кошечки Хаос;
* сытость и настроение питомца;
* запасы угощений;
* открытые настроения питомца;
* ежедневные задания и награды;
* поддерживаемые незавершённые партии.

При запуске через **Яндекс Игры** игра также использует Yandex Player API для синхронизации сохранения с облаком. При наличии локального и облачного сохранения выбирается более актуальная версия прогресса.

При обычном локальном запуске игра продолжает использовать `localStorage`.

Очистка данных сайта в браузере может удалить локальное сохранение.

## Yandex Games

Опубликованная версия:

**https://yandex.ru/games/app/554837?lang=ru**

При запуске на поддерживаемом домене игра подключает Yandex Games SDK и использует:

* `LoadingAPI.ready()` — сообщение платформе о завершении загрузки;
* `GameplayAPI.start()` и `GameplayAPI.stop()` — сигналы начала и остановки игрового процесса;
* `Player API` — загрузка и облачная синхронизация прогресса;
* полноэкранную рекламу;
* rewarded-рекламу с наградой для Кошечки Хаос.

Полноэкранная реклама показывается между игровыми сессиями с ограничением по частоте.

Rewarded-реклама позволяет получить печенье и дополнительные лапки дружбы. Для неё действует дневной лимит.

При обычном локальном запуске без SDK основная игра остаётся работоспособной, но функции платформы Яндекс Игр — реклама и облачная синхронизация — недоступны.
